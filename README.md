# مقاضي العائلة

قائمة مقاضي واحدة لكل البيت، تتحدّث عند الجميع، وتُثبَّت على الجوال مثل تطبيق، مع **إشعارات حقيقية على الجوال** تصل حتى لو كان التطبيق مغلقًا.

- واجهة عربية RTL كاملة، وضع داكن/فاتح، ومتجاوبة للجوال والكمبيوتر.
- خادم Node/Express + SQLite — بلا خدمات خارجية وبلا حساب سحابي.
- تسجيل دخول بدعوة فقط، وكلمات مرور مُشفَّرة (scrypt).
- PWA قابلة للتثبيت على أندرويد وآيفون.
- إشعارات Web Push قياسية (VAPID) — لا Firebase ولا مفاتيح دفع.

## التشغيل على الكمبيوتر

```bat
start-family.bat
```

يفتح: `http://localhost:8787` — الخادم نفسه يقدّم الواجهة والـAPI معًا.

## التشغيل على الجوال (أندرويد / آيفون)

```bat
MOBILE-LINK.cmd
```

سيطبع رابطًا عامًّا بصيغة `https://....trycloudflare.com` وينسخه للحافظة:

1. افتح الرابط في متصفح الجوال.
2. سجّل الدخول بحساب العائلة (أو أنشئ أول حساب إذا كان الخادم جديدًا).
3. **أندرويد:** قائمة كروم ← «إضافة إلى الشاشة الرئيسية».
   **آيفون:** سفاري ← «مشاركة» ← «إضافة إلى الشاشة الرئيسية».
4. افتح التطبيق من الأيقونة، ثم من لوحة الرئيسية اضغط **«تفعيل الإشعارات»** واسمح بها.
5. اضغط **«إرسال تجربة»** للتأكد من وصول التنبيه.

بعد التفعيل يصلك تنبيه على الجوال عند إضافة أي طلب، أو تسجيل شراء، أو حذف منتج، أو إنهاء قائمة أسبوعية — من أي فرد في العائلة.

> الرابط مؤقت: يبقى ما دام هذا الجهاز يعمل ونفق Cloudflare شغّالًا. لإصدار رابط جديد: `MOBILE-LINK.cmd -Restart`.
> لإيقاف كل شيء أغلق نافذة الخادم/النفق أو أوقف عمليات `node` و`cloudflared`.

### ملاحظات الإشعارات

- **أندرويد (كروم):** يعمل مباشرة بعد السماح بالإشعارات.
- **آيفون:** يتطلب iOS 16.4 أو أحدث، ويجب فتح التطبيق من الأيقونة المضافة إلى الشاشة الرئيسية (وليس من تبويب سفاري).
- الإشعارات تعمل عبر HTTPS فقط؛ لذلك استخدم رابط `MOBILE-LINK.cmd` وليس `http://localhost`.
- نسخة **APK** الحالية (WebView) لا تدعم Web Push. استخدم نسخة الويب المثبّتة من الرابط أعلاه؛ وإذا كانت هناك حاجة لإشعارات داخل APK فهذا يحتاج Firebase/FCM وإعدادًا منفصلًا.
- التطبيق يحدّث القائمة تلقائيًا كل 20 ثانية أثناء فتحه، ويسحب إشعارات الخادم بعد كل عملية.

## أول حساب على خادم جديد

- شغّل التطبيق وافتح شاشة الإعداد.
- إذا كان الخادم يضبط `SETUP_TOKEN` في `server/.env`، أدخل الرمز في حقل «رمز الإعداد».
- بعد إنشاء حساب المالك، توزَّع الدعوات من شاشة «العائلة» ← «إضافة عضو».

## الاختبارات

```bat
cd server
npm.cmd test
```

98 اختبارًا: المصادقة، العزل بين العائلات، الجلسات، الواجهة في JSDOM، الإشعارات، وخدمة PWA من نفس الأصل.

## الإعدادات

انسخ `server/.env.example` إلى `server/.env` وعدّل:

| المتغير | الوظيفة |
|---|---|
| `JWT_SECRET` | سرّ توقيع الجلسات (32 حرفًا على الأقل) — إلزامي. |
| `SETUP_TOKEN` | رمز لمرة واحدة لإنشاء أول حساب على خادم جديد. |
| `REQUIRE_INVITE` | يجب أن يبقى `true` في الإنتاج. |
| `TRUST_PROXY` | `true` عند التشغيل خلف نفق/بروكسي TLS. |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | اختياريان؛ إن تُركا فارغين يُولَّد زوج المفاتيح مرة واحدة في `server/data/vapid.json`. |
| `DATABASE_URL` | مسار SQLite (افتراضي `./data/app.db`). |

> لا ترفع `server/.env` أو `server/data/` إلى Git. الملفات مستثناة تلقائيًا.

## البنية

```
www/                 واجهة PWA (HTML/CSS/JS) + service worker
server/src/          Express API + SQLite + Web Push
server/test/         اختبارات node:test
scripts/mobile-link.ps1  نفق Cloudflare لرابط الجوال
start-family.bat     تشغيل محلي (كمبيوتر)
MOBILE-LINK.cmd      رابط HTTPS للجوال والكمبيوتر
```

## الأمان

- لا تشارك رابط النفق علنًا؛ من يملك الرابط يصل إلى شاشة الدخول (لكن التسجيل بدعوة فقط).
- غيّر كلمة مرور المالك الافتراضية إن كانت مؤقتة، وفعّل `SETUP_TOKEN` قبل أول تشغيل على استضافة عامة.
- حدّ معدل محاولات الدخول مفعّل افتراضيًا (10 محاولات / 15 دقيقة / IP) — تأكد أن `TRUST_PROXY=true` خلف النفق حتى يُقرأ IP الحقيقي.
